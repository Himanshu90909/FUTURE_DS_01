# Project 2 — Excel Sales Dashboard

This project presents an executive-ready Excel dashboard built from the
Superstore transaction dataset.

## Included

- KPI cards for sales, profit, margin, and orders
- Regional sales and profit comparison
- Monthly sales trend
- Top-product and sub-category summaries
- Power BI guidance and methodology notes

Open `FUTURE_DS_01_Excel_Dashboard.xlsx` in Microsoft Excel or a compatible
spreadsheet application.

## Skills demonstrated

- Dashboard design
- Business KPI presentation
- Excel charts and summary tables
- Conditional formatting
- Executive recommendations
