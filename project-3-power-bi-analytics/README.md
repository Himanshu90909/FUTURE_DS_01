# Project 3 — Power BI Sales Analytics

This project contains the Power BI implementation guide and reusable DAX
measures for an interactive sales-performance report.

## Included

- Recommended report pages and visuals
- Suggested slicers and data model
- Sales, profit, margin, orders, customers, and time-intelligence measures
- Regional, product, category, segment, fulfillment, and discount analysis

Load the shared `superstore_sales.csv` file from the repository root into
Power BI, then use `POWER_BI_GUIDE.md` and `measures.dax` to build the report.

## Skills demonstrated

- Power BI data modeling
- DAX measure design
- Time-intelligence analysis
- Interactive business reporting
