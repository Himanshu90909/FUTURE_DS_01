# Project 1 — Python Sales Performance Analysis

This project analyzes transaction-level Superstore sales data with Python.
It generates KPI tables, regional/category/product summaries, monthly trends,
and supporting charts.

## Run

From the repository root:

```bash
streamlit run project-1-python-sales-analysis/app.py
```

The app uses the shared `superstore_sales.csv` dataset in the repository root.
The original batch analysis is still available with:

```bash
python project-1-python-sales-analysis/analysis.py
```

## Skills demonstrated

- Data cleaning and validation
- Grouped business analysis with pandas
- KPI calculation
- Trend and profitability analysis
- Automated chart generation
